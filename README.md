# Crypto AI V6

Tableau de bord pédagogique de trading crypto **100 % virtuel** sous Streamlit.

- Cours et historiques publics CoinGecko (quotas et indisponibilités possibles)
- Analyse SMA / RSI / MACD et comparaison de deux stratégies
- Backtesting simplifié sur 90 ou 180 jours
- Robot de simulation déclenché manuellement, sans exécution en arrière-plan
- Opérations fictives, limites d'allocation et sauvegarde JSON

## Démarrer

```bash
pip install -r requirements.txt
streamlit run app.py
```

**Aucun ordre réel. Aucune IA prédictive. Aucun rendement garanti.**
